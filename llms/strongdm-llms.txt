# StrongDM

> StrongDM is a Zero Trust Privileged Access Management (PAM) platform that brokers and governs access to infrastructure — databases, servers, Kubernetes clusters, cloud resources, and network devices — with continuous authorization, full session audit, and no standing privileges. The StrongDM Admin API is a gRPC control-plane API, wrapped by first-party SDKs (Go, Java, Python, Ruby, C#) with REST-like ergonomics and request signing. This file was generated by the API Evangelist enrichment pipeline from StrongDM's public developer surface.

## APIs

- [StrongDM Admin API](https://docs.strongdm.com/): gRPC control-plane API for managing resources, accounts, roles, access grants, gateways, relays, secret stores, and audit logs. Auth: API access key + secret key. Regions: app.strongdm.com (US), app.uk.strongdm.com (UK), app.eu.strongdm.com (EU).

## SDKs and tooling

- [Go SDK](https://pkg.go.dev/github.com/strongdm/strongdm-sdk-go): `go get github.com/strongdm/strongdm-sdk-go/v17`
- [Python SDK](https://pypi.org/project/strongdm/): `pip install strongdm`
- [Ruby SDK](https://rubygems.org/gems/strongdm): `gem install strongdm`
- [Java SDK](https://central.sonatype.com/artifact/com.strongdm.api/strongdm): `com.strongdm.api:strongdm`
- [C# SDK](https://github.com/strongdm/strongdm-sdk-csharp): source on GitHub
- [Terraform provider](https://registry.terraform.io/providers/strongdm/sdm): `strongdm/sdm`
- sdm CLI: local client for login, connect, ssh, audit, replay (install from Admin UI / StrongDM Desktop)
