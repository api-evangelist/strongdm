## Home

- [AWS](https://docs.strongdm.com/admin/deployment/integrations/aws.md): The Amazon Web Services (AWS) cloud can be used to host StrongDM nodes and manage secrets. StrongDM can govern access to AWS CLI and many AWS resource types.
- [GCP](https://docs.strongdm.com/admin/deployment/integrations/gcp.md): The Google Cloud Platform (GCP) can host StrongDM nodes, manage secrets, and manage users. StrongDM can govern access to gcloud and many GCP resource types.

- [PagerDuty Integration](https://docs.strongdm.com/admin/deployment/integrations/pagerduty.md): StrongDM integration with PagerDuty that allows on-call members of PagerDuty schedules to receive access to specified resources within StrongDM while on call.
- [Incident.io Integration](https://docs.strongdm.com/admin/deployment/integrations/incidentio.md): StrongDM integration with Incident.io that allows on-call members of Incident.io schedules to receive access to specified resources within StrongDM while on call.
- [Okta](https://docs.strongdm.com/admin/deployment/integrations/okta.md): StrongDM integrates with Okta as an identity provider, handling SSO, SCIM user/group provisioning, and MFA. StrongDM can also govern access to Okta itself.
